## 已完成：阶段 4

完成内容：

- 实现 4 字节大端长度帧、65536 字节上限、规范 JSON 与 CRC32 仿真封装。
- 校验固定协议方向、版本、消息 ID、sequence、时间戳、状态版本和消息类型。
- 实现 HELLO/ACK 握手、握手前业务门禁、心跳、3500/6000 ms 降级/断开。
- 实现 A Server/B Client、B 站 1/2/5 秒退避重连和重连后的双向全量同步。
- socket 只在 runner/Qt worker 线程创建、读写与关闭，停止事件可中断退出。
- 接入 `PeerSyncService` 语义门禁；坏同步、版本回退和未知边界不进入控制器。
- 发送队列限制 256 条；新会话清空旧增量，避免过期状态跨重连补发。
- 提供协议技术说明与 Hypothesis 属性测试；全量回归 `103 passed`。

阶段决定：CRC32 明确只用于课程仿真的意外损坏检测，不宣称认证、加密或铁路安全通信能力；活性使用本站单调接收时钟，不依赖对站系统时钟。
