# TCC 进路生命周期与站内运行设计

日期：2026-10-12

## 1. 目标

本次修订把发车进路、区间运行、接车进路和目标站内运行拆成连续但职责明确的阶段，使多辆列车能够在同一方向上依次发车，并由人工为最前方列车建立接车进路。

核心规则如下：

- 发车只要求存在与当前方向匹配的发车进路，不要求预先建立接车进路；
- 没有接车进路时，列车停在目标站进站信号机外方的最后一个区间区段；
- 接车进路只分配给当前方向上最靠近目标站、尚未获得接车进路的列车；
- 发车和接车进路在列车实际通过后自动删除，下一辆列车必须重新建立；
- 列车进入目标站后继续通过股道，越过车站另一端信号机后才完成运行并从图中消失。

## 2. 列车状态机

列车运行阶段为：

```text
WAITING
  -> DEPARTING
  -> INTERVAL_RUNNING
  -> WAITING_RECEIVE_ROUTE
  -> RECEIVING
  -> STATION_RUNNING
  -> EXITING
  -> ARRIVED
```

界面使用中文显示：待发、发车进路运行、区间运行、等待接车进路、接车进路运行、站内运行、驶出车站、运行完成。

`STOPPED` 继续表示全局暂停或前车占用造成的停车；另用运行阶段或停车原因区分“等待接车进路”，防止自动恢复逻辑在没有接车进路时误启动车辆。

## 3. 发车与发车进路

### 3.1 发车条件

点击“发车”时只检查：

- 当前选中列车处于待发状态；
- 当前方向对应出发站存在一条已建立、未被其他列车锁闭的发车进路；
- 入口区段和前车间隔满足现有多车安全条件；
- 最大速度值有效；
- 双站通信已建立。

不检查接车进路。

列车的发车方式直接由实际发车进路派生：正线发车为 `MAIN/1G`，侧线发车为 `SIDE/3G`。不再从界面下拉框读取。

### 3.2 自动释放

列车完全进入区间首段后删除发车进路：

- A→B：列车越过 A 站 SN 并进入 G01；
- B→A：列车越过 B 站 X 并进入 G38。

删除后同站可重新建立新的发车进路；下一辆列车仍需满足区间间隔条件。

## 4. 接车进路分配与等待

### 4.1 分配规则

建立接车进路时，系统把该进路自动分配给当前方向上最靠近目标站、尚未获得接车进路的活动列车。排序使用沿当前运行方向的累计线路位置，位置越靠近目标站优先级越高。

该进路一旦分配并锁闭，不得被后车抢占。前车通过并自动释放后，后车必须等待操作者重新建立接车进路。

### 4.2 无接车进路停车

- A→B 列车没有 B 站接车进路时，停在 G38 末端、B 站 X 信号机外方；
- B→A 列车没有 A 站接车进路时，停在 G01 末端、A 站 SN 信号机外方。

新进路分配给该车后，若没有全局暂停且目标站进路可用，列车自动恢复接车运行。

### 4.3 自动释放

- A→B：列车越过 B 站 X1 或 X3 后删除接车进路；
- B→A：列车越过 A 站 S1 或 S3 后删除接车进路。

删除进路不会停止列车，列车继续在目标站内运行直至驶出车站。

## 5. 目标站运行

- A→B：从 B 站 X 进入，沿接车进路进入 1G 或 3G，越过 X1 或 X3 后释放进路，继续向右运行，越过 B 站 S 后完成；
- B→A：从 A 站 SN 进入，沿接车进路进入 1G 或 3G，越过 S1 或 S3 后释放进路，继续向左运行，越过 A 站 X 后完成。

站内运动使用与2D站场信号坐标一致的归一化位置，不能把列车从最后一个区间直接标记为到达。

## 6. 进路白光带

白光带只覆盖实际进路：

| 方向 | 进路 | 正线 | 侧线 |
|---|---|---|---|
| A→B | A站发车 | X1—SN | X3—SN |
| A→B | B站接车 | X—X1 | X—X3 |
| B→A | B站发车 | S1—X | S3—X |
| B→A | A站接车 | SN—S1 | SN—S3 |

进路自动删除后白光带同步消失。

## 7. 列车状态区

发车方式和接车方式改为只读显示，不再使用下拉框。布局为：

```text
第一行：查看列车｜发车方式｜接车方式｜当前列车状态｜设置速度
第二行：当前分区｜安全状态｜当前速度｜前车距离
第三行：当前码序｜线路限速｜最后应答器｜制动距离
```

- 尚无发车进路或列车未发车时显示“发车进路尚未建立”；
- 当前列车未获得接车进路时显示“接车进路尚未建立”；
- 已使用的发车进路释放后，列车仍保存并显示本次运行的发车方式；
- 接车方式只显示在被分配该进路的最前方列车上；
- 删除“分区位置”和“目标速度”；安全状态占用原“分区位置”位置；
- 最大速度仍使用固定选项，并允许运行中实时生效。

## 8. 2D列车显示

- A→B 待发列车停在 A 站 X 信号机右侧；
- B→A 待发列车停在 B 站 S 信号机左侧；
- 多辆待发列车紧凑排列，上方依次显示 `x1、x2、x3……`；
- 区间列车继续按38个区段绘制；
- 等待接车进路时固定绘制在目标站进站信号机外方；
- 接车和站内运行时根据站内位置沿正线或侧线绘制；
- 越过目标站另一端信号机后才从2D图中移除。

## 9. 错误反馈和安全边界

错误弹窗继续使用“操作失败／当前状态／处理建议”三段式，并至少覆盖：

- 未选择有效列车；
- 当前列车不是待发状态；
- 出发站尚未建立发车进路；
- 发车进路被其他列车锁闭；
- 入口区段占用或前车间隔不足；
- 建立的接车进路暂时没有可分配列车；
- 接车进路已经分配给其他列车；
- 锁闭进路被人工取消；
- 站内或区间目标位置被前车占用。

暂停、复位和一键清车继续遵守现有全局控制规则；复位后的列车回到出发点，但已经被自动删除的进路不会恢复。
